# Citadel Studio

Official website for Citadel Studios and ItzZyphron.

A lightweight static website serving as a central hub for content, projects, community links, applications, and resources related to Citadel Studios and ItzZyphron.

## Features

- Modern responsive design
- Mobile-friendly navigation
- Centralized community links
- Creator and project showcase
- Application portal for community members
- Custom branding and assets
- License and contact pages
- GitHub Pages compatible deployment

## Project Structure

```text
citadel.studio/
├── assets/

```

## Deployment

This project is designed for static hosting providers such as:

- GitHub Pages
- Cloudflare Pages
- Vercel
- Netlify

### GitHub Pages

1. Fork or clone the repository.
2. Push changes to the `main` branch.
3. Enable GitHub Pages in repository settings.
4. Configure your custom domain if desired.

The repository includes a `CNAME` file for custom domain configuration.
